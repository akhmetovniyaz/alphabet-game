# 🎮 Угадай букву - Alphabet Game

Образовательное веб-приложение для детей, помогающее изучать английский алфавит в веселой и интерактивной форме.

## 🌟 Возможности

- **Интерактивное обучение**: Угадывай первую букву английских слов по изображениям
- **Аудио произношение**: Слушай правильное произношение букв и слов
- **Отслеживание прогресса**: Счётчик правильных и неправильных ответов
- **Сохранение сессии**: Прогресс сохраняется в LocalStorage
- **Красочный дизайн**: Анимации, яркие цвета, отзывчивый интерфейс
- **26 объектов**: Полный английский алфавит от A до Z

## 🚀 Как использовать

1. Откройте `index.html` в любом современном веб-браузере
2. Посмотрите на изображение (эмодзи)
3. Выберите первую букву английского названия объекта
4. Получите мгновенную обратную связь:
   - ✅ Зелёный = Правильно (+ звук произношения)
   - ❌ Красный = Неправильно (показывается правильный ответ)
5. Нажмите "Следующий" для продолжения
6. Используйте "Сбросить счёт" для начала заново

## 🛠️ Технологии

- **HTML5** - структура приложения

## 🎯 Игровой процесс

1. Случайный объект отображается в виде эмодзи
2. Предлагается 4 варианта букв (1 правильная + 3 неправильные)
3. После ответа:
   - Показывается название объекта
   - Воспроизводится произношение (при правильном ответе)
   - Обновляется счёт
   - Сохраняется прогресс
4. Все 26 объектов используются без повторений до завершения цикла
